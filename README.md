# ACVGstudio

ACVGstudio is a desktop AI filmmaking studio. 3D grey-box scenes drive generative
image and video models, so a filmmaker can go from script to a finished multi-shot
short film inside a single window: storyboard, character and wardrobe tagging,
motion and camera blocking, AI-directed plans, local or remote generation, editing,
sound, and delivery.

## Status

Early development. The V1.0 design baseline is approved; implementation has not
started, and no feature described in the design is delivered yet.

## Dependencies and licensing

The planned product builds on Blender and ComfyUI, both of which are GPL-licensed
upstream. Distribution and licensing terms have not been finalized. Built-in
assets, models, and media must each have a traceable source and a compatible
license before they are bundled.

The product name and branding do not imply endorsement by the Blender or ComfyUI
projects.
